## 1. Conda Basic Management

### Conda Update

```bash
conda update -n base -c defaults conda
```

### Check version

```bash
conda --version
```

### Info

```bash
conda info
```

---

## 2. Environment Management

### Environment Create

```bash
conda create -n ENV_NAME python=PYTHON_VERSION
```

Example:

```bash
conda create -n myenv python=3.10
```

- Python official release page: <https://www.python.org/downloads/>
- Python official version support page: <https://devguide.python.org/versions/>

### Environment Remove

```bash
conda env remove -n ENV_NAME
```

### Environment List

```bash
conda env list
```

### Environment Copy

```bash
conda create -n TARGET_ENV --clone SOURCE_ENV
```

---

## 3. Package Management

### Package Install

```bash
conda install PACKAGE_NAME
```

Example:

```bash
conda install numpy pandas
```

### Package Uninstall

```bash
conda uninstall PACKAGE_NAME
# or
conda remove PACKAGE_NAME
```

### Package Update

```bash
conda update PACKAGE_NAME
# or
conda upgrade PACKAGE_NAME
```

> `conda update --all` will update all packages at once.
{: .prompt-tip }

### Package List

```bash
conda list
```

> - To search for a specific package, use `conda list | grep PACKAGE_NAME`
> - To save the package list to a file, use `conda list > requirements.txt`
{: .prompt-tip }
