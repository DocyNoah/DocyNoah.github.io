W&B(Weights & Biases) API는 Python 코드에서 W&B의 모든 기능을 제어할 수 있게 해주는 도구이다.
이 포스트에서는 W&B API의 주요 기능과 실용적인 사용 방법을 알아본다.

## 기본 설정

W&B API 사용을 위한 기본 설정:

```python
import wandb
api = wandb.Api()  # API 인스턴스 생성
```

## 주요 기능

### 1. 단일 Run 조회

단일 run 조회 방법:

```python
# PROJECT/RUN_ID 형식으로 run을 조회
run = api.run("username/project/run_id")

# run의 주요 정보 조회
print(f"Run name: {run.name}")
print(f"Run config: {run.config}")
print(f"Run summary: {run.summary}")
```

### 2. 여러 Run 조회

run 조회 및 필터링 방법:

```python
# 프로젝트의 모든 run 조회
runs = api.runs("username/project")

# 필터링 조건을 사용하여 run 조회
filtered_runs = api.runs("username/project", 
                        filters={"group": "experiment_group"})

# run 정보 출력
for run in runs:
    print(f"Run ID: {run.id}")
    print(f"Run name: {run.name}")
    print(f"Run config: {run.config}")
    print("---")
```

## 실용적인 사용 예시

### 1. Run 그룹 변경

#### 단일 Run의 그룹 변경

```python
# 특정 run의 그룹을 변경
run = api.run("username/project/run_id")
run.group = "new_group_name"
run.update()  # 변경사항 저장
```

#### 여러 Run의 그룹 일괄 변경

```python
# 특정 그룹에 속한 모든 run의 그룹을 변경
runs = api.runs("username/project",
                filters={"group": "old_group_name"})

for run in runs:
    run.group = "new_group_name"
    run.update()
```

### 2. Run 태그 관리

```python
# run에 태그 추가
run = api.run("username/project/run_id")
run.tags.append("new_tag")
run.update()

# run에서 태그 제거
run.tags.remove("old_tag")
run.update()
```

### 3. Run 설정 변경

```python
# run의 설정 변경
run = api.run("username/project/run_id")
run.config.update({"learning_rate": 0.001})
run.update()
```

## 주의사항

1. API 호출 시 적절한 권한 필요
2. 대량의 run 조회 시 필터링으로 필요 데이터만 조회
3. `update()` 메서드 미호출 시 변경사항 미저장
