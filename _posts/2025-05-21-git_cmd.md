## add

스테이징 영역에 파일 추가

```bash
git add <file_name>          # 특정 파일 추가
git add .                    # 현재 디렉토리의 모든 변경사항 추가
git add -p                   # 변경사항을 확인하며 부분적으로 추가
git add -u                   # 추적 중인 파일들만 스테이징
```

## commit

스테이징된 변경사항을 저장소에 기록

```bash
git commit -m "message"         # 커밋 메시지와 함께 커밋
git commit -am "message"        # 추적 중인 파일들을 자동 스테이징하고 커밋
git commit --amend              # 마지막 커밋 수정
```

## push

로컬 변경사항을 원격 저장소에 업로드

```bash
git push origin <branch>        # 특정 브랜치를 원격 저장소에 푸시
git push -u origin <branch>     # 브랜치를 푸시하고 추적 설정
git push --force                # 강제 푸시 (주의 필요)
git push --tags                 # 태그 푸시
```

## pull

원격 저장소의 변경사항을 로컬로 가져와 병합

```bash
git pull origin <branch>        # 원격 브랜치의 변경사항 가져와서 병합
git pull --rebase               # rebase 방식으로 pull 수행
```

## fetch

원격 저장소의 변경사항을 로컬로 가져오기 (병합하지 않음)

```bash
git fetch origin                 # 모든 브랜치의 변경사항 가져오기
git fetch origin <branch>        # 특정 브랜치의 변경사항만 가져오기
git fetch --all                  # 모든 원격 저장소에서 가져오기
```

## merge

브랜치 병합

```bash
git merge <branch>               # 현재 브랜치에 지정 브랜치를 병합
git merge --no-ff <branch>       # fast-forward 없이 병합
git merge --abort                # 병합 충돌 시 병합 취소
```

## reset

커밋 이력 되돌리기

```bash
git reset --soft HEAD^           # 최근 커밋을 스테이징 영역으로 되돌림
git reset --mixed HEAD^          # 최근 커밋을 작업 디렉토리로 되돌림
git reset --hard HEAD^           # 최근 커밋을 완전히 삭제
git reset --hard <commit>        # 특정 커밋으로 되돌림
```

## revert

커밋 변경사항을 취소하는 새로운 커밋 생성

```bash
git revert <commit>              # 특정 커밋 되돌리기
git revert HEAD                  # 최근 커밋 되돌리기
git revert --no-commit           # 커밋하지 않고 되돌리기
```

## cherry-pick

특정 커밋을 선택적으로 현재 브랜치에 적용

```bash
git cherry-pick <commit>         # 특정 커밋 가져오기
git cherry-pick -n <commit>      # 커밋하지 않고 변경사항만 가져오기
git cherry-pick --abort          # cherry-pick 취소
```

## rebase

브랜치의 기준점을 변경

```bash
git rebase <branch>              # 현재 브랜치를 대상 브랜치 위로 재배치
git rebase -i HEAD~n             # 최근 n개의 커밋을 대화형으로 재배치
git rebase --abort               # rebase 작업 취소
```

## remote

원격 저장소 관리

```bash
git remote -v                    # 원격 저장소 목록 확인
git remote add <name> <url>      # 원격 저장소 추가
git remote remove <name>         # 원격 저장소 삭제
git remote rename <old> <new>    # 원격 저장소 이름 변경
git remote set-url <name> <url>  # 원격 저장소 URL 변경
```
