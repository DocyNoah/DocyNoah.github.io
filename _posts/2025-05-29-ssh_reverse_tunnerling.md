SSH Reverse Tunneling은 방화벽이나 NAT 뒤에 있는 내부 서버에 외부에서 접근하기 위한 방법이다.
일반적인 SSH 연결과는 달리, 내부 서버가 외부 서버로 먼저 SSH 연결을 수립하고 이를 통해 터널을 형성하여 외부에서 내부로의 접근을 가능하게 한다.

## Reverse Tunneling 설정 과정

### 1. 외부 서버 ssh 설정

외부 서버 SSH 서비스 활성화

```bash
sudo systemctl enable sshd
sudo systemctl start sshd
```

- `enable`: 시스템 부팅 시 SSH 서비스가 자동으로 시작되도록 설정
- `start`: SSH 서비스를 즉시 시작

### 2. 내부 → 외부 터널 생성

내부 서버에서 다음 명령어로 외부 서버와 터널을 생성

```bash
ssh -R <외부_서버_포트>:localhost:<내부_서버_포트> <외부_서버_계정>@<외부_서버_주소> -p <외부_서버_SSH_포트>
```

수행 작업:

- 외부 서버로 SSH 연결
- 동시에 리버스 터널 생성

명령어 구성 요소 설명:

- `-R`: Reverse 터널링 옵션으로, 외부 서버에서 내부 서버로의 포트 포워딩을 설정
- `<외부_서버_포트>`: 외부 서버에 생성될 포트 번호 (예: 2222)
- `localhost:<내부_서버_포트>`: 내부 서버의 접속할 포트 (일반적으로 SSH 포트인 22 사용)
- `<외부_서버_계정>`: 외부 서버 접속에 사용할 계정명
- `<외부_서버_주소>`: 외부 서버의 도메인 또는 IP 주소
- `-p <외부_서버_SSH_포트>`: 외부 서버의 SSH 포트 (기본값: 22)

### 3. 외부 → 내부 접속

외부에서 터널을 통한 내부 서버 접속 명령어

```bash
ssh -p <터널_포트> <내부_서버_계정>@<외부_서버_주소>
```

수행 작업:

- 외부 서버에 설정된 터널 포트로 연결
- 터널을 통해 내부 서버의 SSH 포트로 연결
- 결과적으로 내부 서버의 `<내부_서버_포트>` 포트로 접속

명령어 구성 요소 설명:

- `-p <터널_포트>`: 2단계에서 설정한 외부 서버의 포트 번호
- `<내부_서버_계정>`: 내부 서버에 접속할 때 사용할 계정
- `<외부_서버_주소>`: 외부 서버의 도메인 또는 IP 주소
